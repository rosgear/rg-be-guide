## <img src="https://raw.githubusercontent.com/rosgear/rg-be-guide/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Модуль «Справочная информация»

Модуль входит в состав Панели управления GePanel.

Справочная информация для пользователей веб‑приложения РосГир, содержащая инструкции, руководства и ответы на часто задаваемые вопросы.

### Установка

Для добавления модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-guide
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-guide": "*"
}
```
или скачать архив на [странице модуля](https://rosgear.ru/component/rg-be-guide/) в каталоге приложений РосГир.

После добавления модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

## <img src="https://raw.githubusercontent.com/rosgear/rg-be-guide/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module «Guide»

The module is part of the GePanel Control Panel.

Help information for users of the RosGear web application, containing instructions, guides, and answers to frequently asked questions.

### Installation

To add the module to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-guide
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-guide": "*"
}
```
or download the archive from the [module page](https://rosgear.ru/component/rg-be-guide/) in the RosGear application catalog.

After adding the module to the project, install it into the web application edition using the GePanel Control Panel.
